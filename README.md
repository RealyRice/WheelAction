# WheelAction (Fabric 1.21.11)

Мод для Fabric **1.21.11**, который выполняет настраиваемую команду при **нажатии колёсика мыши** по нику игрока в чате.

## Как работает

- В чате наведитесь на ник (или слово), нажмите **среднюю кнопку мыши**.
- Мод возьмёт ник и выполнит команду по шаблону из настроек (например: `/duel {name}`).

## Настройка

Рекомендуется установить **Mod Menu** (идущий отдельным модом), чтобы открыть экран настроек.

Параметр:

- **Command template**: строка-шаблон, где `{name}` будет заменён на ник.

## Разработка

### Сборка

```bash
./gradlew build
```

Артефакт будет в `build/libs/`.
